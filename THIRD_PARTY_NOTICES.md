# Third-party software

## ImageMagick

This project builds and embeds the ImageMagick engine from the upstream
`ImageMagick/ImageMagick` repository at build time.

ImageMagick License:
https://imagemagick.org/license/

The upstream LICENSE file is fetched with the ImageMagick source during CI.
When distributing the application, include the applicable ImageMagick license
and attribution required by the upstream license.
